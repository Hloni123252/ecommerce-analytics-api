## 📌 Overview

An end-to-end **data platform** demonstrating:

- **Backend Engineering** — FastAPI + async SQLAlchemy 2.0
- **Analytics at Scale** — SQL aggregations over 10k+ orders
- **Background Jobs** — Celery tasks with a caching layer
- **Data Engineering** — Faker + Pandas for realistic data generation
- **Machine Learning** — RandomForest churn prediction with time-based validation
- **Production Patterns** — Repository layer, Pydantic schemas, Docker-ready config

This project is part of a portfolio demonstrating **Back-End Engineering + Data Science + ML**.
